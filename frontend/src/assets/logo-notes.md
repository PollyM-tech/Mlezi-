# Mlezi logo

`logo.svg` is a vector trace of the existing `logo.png`, with simplified two-colour paths and an editable text tagline. It contains no embedded bitmap. The original PNG is preserved as source artwork.

`public/favicon.svg` uses the caregiver symbol alone for small browser tabs. `public/favicon.ico` and the PNG icons remain browser/device fallbacks.

The SVG keeps the original 500 × 500 layout to preserve existing header/footer crop styles. This is a traced reproduction, not the original designer's vector source.
