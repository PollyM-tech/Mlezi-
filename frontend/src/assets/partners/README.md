# Partner artwork

The Lintech logo is saved at `../lintech-logo.png` and imported directly by
`src/components/Partners.jsx`. Replace that file to update the logo; a rebuild
includes the updated artwork in the public page.

Use the complete original artwork, without screenshot padding or clipping.
Images keep their proportions and fit inside a compact, responsive partner card.
No partner website link is configured until its correct URL is provided.
