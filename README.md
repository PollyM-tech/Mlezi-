# Mlezi

A Kenyan caregiver marketplace using **React + JavaScript + Convex**. Convex handles authentication, database functions and file storage.

```bash
cd frontend
npm install
npm run dev
```

See [current setup and checks](frontend/README.md), [security/identity implementation](Documentation/production-security-implementation.md), [SEO and regional discovery](Documentation/seo-and-regional-discovery.md), and [Flask retirement](Documentation/flask-retirement.md). Automated checkout remains disabled pending Paystack integration and production setup. The [manual M-Pesa workflow](Documentation/manual-payments.md) provides receipt reporting and administrator-confirmed activation for Paybill 4125123, account mlezicare.

Lintech Telecom is the operator name supplied for the marketplace-only first version. See the [legal review handoff](Documentation/legal-review-handoff.md) and matching policy drafts; final legal particulars and qualified review remain pending.
